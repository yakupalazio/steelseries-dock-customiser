# SteelSeries Dock Customiser — Beta 4

**Independent Windows 11 application for the SteelSeries Arctis Nova Pro Wireless dock's 128 × 64 OLED display.** Customize your OLED layout, preview widgets, follow media and game activity, and explore supported wireless battery telemetry.

**Current public version: 1.0.0-beta.4.1 hotfix (Windows x64; Beta 4 release)**

**[Download Beta 4 for Windows](https://github.com/yakupalazio/steelseries-dock-customiser/releases/download/v1.0.0-beta.4/SteelseriesDockCustomiser-v1.0.0-beta.4-win-x64.zip)** · [Release information and SHA-256](https://github.com/yakupalazio/steelseries-dock-customiser/releases/tag/v1.0.0-beta.4)

## Highlights

- **Community Workshop:** Discover and preview community designs, download profiles, share your own layouts using GitHub sign-in, rate and favorite designs. Workshop is optional; shared designs and author names are public.
- **Beta 4 hotfix:** Restored the dock photo preview and volume wheel indicator/animation. The current ZIP contains the Beta 4.1 hotfix.

- **OLED Studio:** WYSIWYG 128 × 64 pixel editor with a dock photo preview, custom widgets, profiles, and media/game/idle layouts.
- **Polished interface:** Seven interface themes including OLED Black and OLED White, Liquid Glass and Cyberpunk themes, Inter typography and smooth physical-knob animation on the dock photograph.
- **Hardware-aware display control:** safe fallback to the original dock screen; incoming-call and SteelSeries GG GameSense display priority where detectable. Controls may depend on firmware and Windows.
- **Battery monitoring:** optional, read-only indicators for supported SteelSeries, WLMOUSE, Razer, Logitech, ASUS ROG, HyperX, Lamzu and other peripherals; availability depends on model and protocol.
- **Pixel arcade:** secret Konami-code menu with seven OLED mini-games, local high scores, custom Breakout upgrades, Snake wall modes and a small original space shooter.
- **Media tools:** playback information, animations, lyrics options, games and desktop integration.
- **Privacy:** configuration and high scores are saved locally. The optional issue reporting flow opens GitHub and requires the user to submit the issue.

## Install / Kurulum

1. Download the Windows x64 ZIP from the link above.
2. Extract the ZIP completely (don't run the EXE from inside the archive).
3. Open **SteelseriesDockCustomiser.exe** on Windows 11.
4. If an earlier version is running, close it from the system tray before launching Beta 4.
5. Keep the LICENSE, TERMS and THIRD_PARTY_LICENSES files together with the application. Verify the SHA-256 hash available on the release page.

This is an unsigned independent release. Windows SmartScreen may display a warning because the application has not been code-signed. Please download only from this official repository.
