# SteelSeries Dock Customiser 1.0.0 Beta 1

**Public Windows x64 pre-release — Testers wanted!**

SteelSeries Dock Customiser is an independent, free-to-use, closed-source Windows app for designing and streaming 128×64 monochrome OLED layouts on the Arctis Nova Pro Wireless dock. This release is **not affiliated with SteelSeries**.

## Highlights
- Media, game and idle OLED editors with draggable widgets, synced lyrics, customizable progress, clocks, dynamic icons and profiles.
- 1–4 lyric lines and Slide, Fade, Drop, Wipe and Instant lyric transitions.
- Battery and device compatibility catalog with 364 wireless model names across 35 brands, verified Bluetooth GATT/HFP readers and 27 exact CompX HID receiver IDs. Brand recognition is not a promise that the battery percentage will be available.
- ATK 1K dongle CompX battery reading **confirmed by an actual beta tester**; other models are not assumed compatible until tested.
- UI hotfixes for clipped profile/battery buttons, profile mini preview, Quick Guide targeting, Media "No media playing" placeholder, lyric animation settings persistence, customizable battery icons and OLED header illustration.
- Improved **Bug report** experience: opens GitHub Issue forms with prefilled details and optional clean PNG screenshot. Uploading the attachment and submitting require user action on GitHub. Never quietly uploads logs or private files.

## Getting started
1. Download and extract `SteelseriesDockCustomiser-v1.0.0-beta.1-win-x64.zip`.
2. Run `SteelseriesDockCustomiser.exe` (self-contained Windows x64).
3. Read `BETA_TESTING.md` for installation, testing, privacy and feedback steps.
