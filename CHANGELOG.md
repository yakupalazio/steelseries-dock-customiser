# Changelog

## 0.9.4 — Physical OLED one-shot experiment
- Added manual, confirmation-gated **Send to physical dock (10s)** button in Dock Preview.
- Added **Restore SteelSeries UI** button, automatic restore in `finally`, bounded CLI commands and cancel handling.
- Uses separately downloaded, SHA-256-pinned ggoled v0.3.0 for only `img` and `return` commands.
- Real 128×64 image generated by the existing native renderer sent once to the dock: CLI returned 0, and the return command returned 0. Visual verification remains with the device owner.
- Added isolated WinRT/MSIX package-identity experiment; Windows rejected loose registration with 0x80073CFF because Developer Mode is not enabled. No security policy changes or package installations.
- Kept previous v0.9.3 files and public GitHub revision unchanged.

## 0.9.3 — Phone Link battery source
- Read phone battery from accessible status Group in the minimized/open Phone Link window.

## 0.9.2 — SteelSeries GG battery sources
- Read Aerox Gen 2 and Nova Pro battery and spare battery values via local GG Engine state.

## 0.9.1 — Stale Bluetooth suppression
- Rejected old Windows Bluetooth PnP battery values as current percentages.

## 0.9.0 — Battery selection and icon editor
- Added per-device battery selector, icon sprite editor and DualSense experimental HID probe.
